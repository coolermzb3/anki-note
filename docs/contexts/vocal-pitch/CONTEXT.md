# 清唱

本语境定义加入基于乐谱的视唱前，录制、导入和分析单声部人声所使用的语言。

## Language

**清唱**:
录制或导入人声音频、查看音高分析结果并管理已保存音频素材的工作区。它目前不是有乐谱、评分或练习记录的视唱活动。
_Avoid_: 视唱、音高页、分析页

**单声部人声**:
同一时刻至多包含一个有意演唱音高的人声音频。它可以包含轻量环境底噪、呼吸和辅音，但不包括需要可靠识别的伴奏、和声或多人合唱。
_Avoid_: 纯净人声、无噪声录音、复调人声

**基频轨迹**:
单声部人声沿时间排列的基频估计与无音高片段。它是音频分析结果，不是乐谱、离散音符序列或演唱评分。
_Avoid_: 旋律、音符轨道、乐谱

**参考音高**:
把连续基频映射到十二平均律音名时使用的 A4 频率，默认值为 440 Hz。改变参考音高只改变音名中心和音分偏差的解释，不改变已经检测出的基频。
_Avoid_: 标准答案、检测频率、麦克风校准

**音分偏差**:
检测基频相对参考音高下最近十二平均律音高的有符号距离。它描述当前位置的音高关系，不是视唱准确率或演唱评分。
_Avoid_: 得分、识别误差、频率差

**无音高片段**:
分析器无法可靠确认周期性人声基频的时间片段，例如静音、呼吸、辅音或说话声。无音高片段不吸附到最近音符。
_Avoid_: 0 Hz、错误音高、休止符

**音频素材**:
一次新录音、导入的音频文件或从保存区打开的音频。工作区同时只应用一个音频素材；录音始终创建从零开始的新素材，不在播放头处覆盖现有音频。
_Avoid_: 练习记录、音轨、项目

**录音**:
从开始持续到停止的一次音频采集，不能暂停或继续。停止会完成一个不可续录的音频素材，之后再次录音会创建新素材。
_Avoid_: 追加录音、可编辑音轨、录音片段列表

**实时分析**:
录音期间逐步产生的临时基频轨迹，用于即时反馈。录音停止后，离线分析结果会替换它。
_Avoid_: 最终分析、流式录音文件

**离线分析**:
基于完整音频素材产生的基频轨迹。录音停止或文件导入后自动执行，也可以由重新分析操作再次执行。
_Avoid_: 实时预览、后台任务

**基频帧**:
基频轨迹在一个时间位置的统一分析结果，包含基频或无音高状态以及置信度。实时检测和离线检测使用相同语义，不暴露具体检测算法的内部数据。
_Avoid_: 音符事件、采样点、算法窗口

**分析缓存**:
为快速重新打开音频素材而保存的当前基频轨迹及其算法版本和参数。它可由原始音频重建，不是需要长期保留的独立事实。
_Avoid_: 原始数据、分析历史、算法中间状态

**分析配置**:
随音频素材保存、用于解释或重新生成基频轨迹的算法无关设置，包括参考音高、检测范围、有声判断灵敏度和平滑程度。当前设备的麦克风选择不属于分析配置。
_Avoid_: 麦克风设置、检测器内部参数、全局应用设置

**已保存素材**:
用户明确保存的音频素材及其分析缓存。录音和导入文件使用同一保存区；清空工作区不会删除它，删除必须从素材条目明确触发。
_Avoid_: 自动保存、练习历史、备份快照
