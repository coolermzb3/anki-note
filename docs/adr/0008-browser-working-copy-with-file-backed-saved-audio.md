# Browser working copies with file-backed saved audio

Saved audio keeps a browser working copy containing the audio Blob, metadata, and analysis cache, while a selected backup directory stores the audio as a separate binary file for recovery and transfer. Saving remains available without a backup directory but must be labeled as browser-only; audio is never embedded as Base64 in the existing JSON backup files. A finalized source is immutable and identified by a stable material ID plus a content digest computed once at recording completion or import; ordinary synchronization reuses that digest, and recalculates it only when backup-file metadata indicates an external change. Recordings default to compact WebM/Opus at a target 96 kbps, imported files retain their original bytes, and analysis decodes supported files to PCM instead of forcing all sources through a lossy M4A conversion.
